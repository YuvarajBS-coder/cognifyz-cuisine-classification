# Cuisine Classification | Cognifyz Machine Learning Task 3

A machine-learning project that predicts a restaurant's **primary cuisine label** from restaurant details using a multiclass Random Forest classification pipeline. It includes a Streamlit demo, training script, evaluation metrics, confusion-matrix plot, and the dataset used for the project.

## Project objective

Preprocess restaurant data, handle missing values, encode categorical features, split the dataset into training and testing sets, train a classification model, and evaluate its predictions with accuracy and per-class precision/recall/F1-score.

## Dataset

`Dataset.csv` contains restaurant information such as city, country code, average cost for two, booking/delivery availability, price range, aggregate rating, votes, and cuisines. The dataset has multiple cuisines in some rows. For a clear single-label classification task, the **first cuisine listed** is used as the target. The model is trained on the 15 most frequent primary-cuisine labels.

## Features used

- Categorical: City, Currency, table booking, online delivery, delivery-now and order-menu flags
- Numeric: Country code, average cost for two, price range, aggregate rating and votes
- Target: first cuisine listed in `Cuisines`

Restaurant names, addresses, locality, coordinates and the original cuisine field are excluded from input features to avoid directly leaking the answer.

## Run locally (Windows)

1. Install Python 3.10 or later.
2. Open this project folder in VS Code.
3. Open Terminal → New Terminal.
4. Create and activate a virtual environment (optional but recommended):

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

5. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

6. Train the model and create evaluation files:

   ```powershell
   python train_model.py
   ```

7. Launch the app:

   ```powershell
   streamlit run app.py
   ```

The app opens in your browser. If the saved model is not present, run the training script first.

## Project files

- `app.py` — custom Streamlit user interface and prediction form
- `train_model.py` — preprocessing, training, evaluation and chart generation
- `Dataset.csv` — dataset used in the project
- `cuisine_model.joblib` — trained scikit-learn pipeline (generated by training script)
- `metrics.json` — evaluation metrics and class report (generated by training script)
- `graphs/confusion_matrix.png` — confusion matrix (generated by training script)
- `requirements.txt` — Python dependencies

## Evaluation

The script uses a stratified 80/20 train-test split and reports accuracy, precision, recall and F1-score. Results are written to `metrics.json`; the confusion matrix is saved in `graphs/`. Do not claim a specific score unless it matches the generated `metrics.json` for your run.

## Limitations

Cuisine is influenced by menu items, chef expertise and restaurant identity, which are not all present in the available columns. The dataset is imbalanced, and city/cost/rating features alone may not reliably identify cuisine. The prediction should be treated as a demonstration rather than a production recommendation.
